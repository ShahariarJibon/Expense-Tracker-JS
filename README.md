💰 Expense Tracker App
A clean, lightweight, and modern web application built with vanilla HTML5, CSS3, and JavaScript (ES6+) to manage personal finances, track daily/weekly/monthly expenses, and monitor transaction histories seamlessly.

✨ Features
Dashboard Overview: Real-time tracking of current Balance, Total Income, and Total Expenses.

Transaction Management: Add new transactions with descriptions and amounts. Select and delete specific transactions easily.

Advanced Statistics: Interactive stats modal breaking down expenses into Daily, Weekly, and Monthly views.

Dark & Light Mode: Smooth theme-switching mechanism featuring a custom animated switch and LocalStorage preference saving.

Data Persistence: Automatically saves all transactions and balances using browser localStorage.

Utility Options: Quick options via a Burger Menu (App Info, Developer Profile) and Three-Dot Menu (Clear History, Reset App).

Responsive Layout: Fully optimized for mobile screens as well as desktop viewports.

🛠️ Tech Stack
HTML5 – Structure and semantics

CSS3 – Styling, Flexbox, custom components, and responsive design

JavaScript (ES6+) – DOM manipulation, event handling, data calculation, and localStorage integration

FontAwesome – Icons
